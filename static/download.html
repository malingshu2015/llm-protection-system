✨ 核心特性

  • 双层安全过滤 - 本地 + 服务器端双重保护
  • 实时策略同步 - 自动更新最新安全规则
  • 流式响应支持 - 流畅的对话体验
  • 离线过滤能力 - 即使断网也能进行基本安全检测
  • 多账户支持 - 支持多个 LLM 服务账户切换
  • 会话管理 - 完整的对话历史记录
  • 隐私保护 - 所有敏感数据本地加密存储
  • 跨平台一致体验 - Windows、macOS、Linux 统一界面

📋 系统要求

最低配置:
• 操作系统: Windows 10/macOS 10.15/Ubuntu 18.04 或更高版本
• 内存: 4GB RAM
• 存储: 500MB 可用空间
• 网络: 稳定的互联网连接

推荐配置:
• 内存: 8GB RAM 或更高
• 处理器: 双核 2.0GHz 或更高

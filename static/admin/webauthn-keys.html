关于 WebAuthn

什么是 WebAuthn？

WebAuthn 是一种无密码的网络身份验证标准，使用公钥加密技术，比传统密码更安全。

支持的设备：

  • 硬件安全密钥 (YubiKey, Titan Security Key 等)
  • 生物识别 (指纹、面部识别)
  • 平台认证器 (Windows Hello, Touch ID, Face ID)

安全提示：

  • 建议注册至少 2 个密钥作为备份
  • 妥善保管您的安全密钥
  • 如果丢失密钥，请及时删除并注册新密钥

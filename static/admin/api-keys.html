使用指南

如何使用API密钥

将API密钥添加到HTTP请求头中:

X-API-Key: sk-your-api-key-here

示例代码

curl -X GET http://your-domain/api/v1/endpoint \
  -H "X-API-Key: sk-your-api-key-here"

安全最佳实践

  • 不要在代码中硬编码API密钥
  • 使用环境变量存储密钥
  • 定期轮换密钥
  • 为不同环境使用不同密钥
  • 设置IP白名单限制访问
  • 监控密钥使用情况
